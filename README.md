## ✨ Features & Architecture Breakdown

### 1. 🎯 Hero & Real-Time Performance Matrix
- **Hero Unit:** Dynamic ambient visual effects with animated entry typography ("Intelligence, Worn.").
- **Live Performance Strip:** Responsive grid showcasing key technical metrics:
  - `0%` Accuracy Rate
  - `↑0ms` Latency Threshold
  - `72h` Extended Battery Life
  - `4.2g` Ultra-lightweight Total Mass

### 2. ⚡ The Intelligence Inside (Feature Architecture)
- **Ambient Intelligence:** Contextual listening and environmental awareness.
- **Neural Voice:** Tailored voice model adapted to cadence and vocabulary.
- **Privacy Core:** Live security status widget displaying:
  - `On-device model`: ACTIVE
  - `Cloud sync`: OFF
  - `AES-256 encryption`: ENABLED
- **Precision Craft:** Aerospace Grade-5 Titanium chassis & 4mm Synthetic Sapphire crystal.
- **Adaptive OS:** Over-the-air continuous model updates.

### 3. 🕒 Interactive Live Demonstration (Context Scenarios)
A multi-stage timeline showcasing AETHER's ambient assistance across daily routines:
- **07:22 AM · YOUR CONTEXT:** Schedule optimization, slide deck error detection, and cognitive window clearing.
- **11:03 AM · LIVE MEETING:** Real-time budget deviation alerts delivered via silent haptic taps.
- **08:15 PM · WIND DOWN:** Cognitive load recap, automated schedule sharing, and rest protocol activation.

### 4. 🎨 Atelier & Material Finish Switcher
- **Interactive Finish Selector:** Dynamic visual preview supporting **Raw Titanium**, **Midnight PVD**, and **18k Liquid Gold**.
- Exploded material layers highlighting the 4mm sapphire face and Grade-5 titanium housing.

### 5. 🔒 Reservation & Founding Member Circle
- Limited availability CTA targeting 500 founding edition units.
- Direct waitlist invitation system with responsive input validation.

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic Structure, Accessibility ARIA tags)
- **Styles:** Custom Modern CSS3 (Flexbox/Grid, Glassmorphism Backdrop Filters, CSS Custom Properties)
- **Typography:** Inter / Syne Google Fonts via CDN
- **Hosting & Deployment:** GitHub Pages

## 💻 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/amirrkhani/AETHER.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd AETHER
   ```
3. **Open `index.html`** in your browser or launch with VS Code **Live Server**.
